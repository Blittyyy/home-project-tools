There is no universal square-foot coverage per box of tile. Coverage depends on the tile dimensions, pieces per carton, and the manufacturer’s packaging.

The carton label is more useful than a generic “tiles per box” assumption.

<aside class="planning-note" role="note">
  <p class="planning-note__title">Check the carton</p>
  <p class="planning-note__body">Tile size alone does not tell you box coverage. Two products with the same face size can ship with different piece counts and listed coverage.</p>
</aside>

## Why box coverage varies

- Different pieces per carton  
- Different listed coverage (sometimes vs simple face-area math)  
- Format / calibration differences by product line  

## Tiles-per-box method

`nominal box face coverage = tiles per box × tile face area`

## Coverage-per-box method

Many listings state coverage per carton directly:

`boxes = ceil(planned area with waste ÷ coverage per box)`

Prefer the package figure when calculating boxes that way.

## Worked 12×24 example

A **12×24** tile face = **2 sq ft** ([size math](/materials/how-many-12x24-tiles-do-i-need)).

| Tiles per box | Nominal face coverage |
| --- | --- |
| 8 | **16 sq ft** |
| 10 | 20 sq ft |
| 16 | 32 sq ft |

If the manufacturer lists a package coverage figure, use that for the coverage-per-box method — even when face-area math is close.

## Which number should you trust?

Face-area math is a cross-check. Nominal size and listed coverage can differ slightly from width × length ÷ 144. Use the manufacturer/package coverage for purchase when it is provided.
